# Security policy

This project is pre-release; security fixes are applied to the current development branch.

Please report suspected vulnerabilities privately using the repository's GitHub **Security**
tab and its **Report a vulnerability** feature. Do not open a public issue with exploit
details, credentials, personal information, or private editorial material. Include a
minimal reproduction and affected version when possible. Maintainers will coordinate
assessment, remediation, and disclosure through the private report. If private reporting
is unavailable, do not disclose sensitive details publicly; contact the maintainers through
a private channel available on the repository before sharing them.
